# 03 Trees

**Target range:** roughly `1200-1500`

Trees deserve their own section because they appear constantly and have
special-purpose techniques that are much simpler than general graph algorithms.

## Goal before moving on

You should know how to:

- root a tree
- compute parent, depth, and subtree size
- flatten a tree into an array
- answer ancestor and LCA queries
