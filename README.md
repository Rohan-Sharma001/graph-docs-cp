# Graphs in Competitive Programming

This repo is a study path for graph algorithms from the absolute basics up to
roughly Codeforces `1800` level.

## Start here

- Read [What is a graph?](<00 Introduction/README.md>) first.
- Then go through the numbered folders in order.
- Inside each folder, read the files in numeric order and solve a few problems
  before moving on.

## Roadmap

1. [00 Introduction](<00 Introduction/README.md>): what graphs are, common
   graph types, and core terminology
2. [01 Basics](<01 Basics/README.md>): representation, BFS, DFS
3. [02 Core Patterns](<02 Core Patterns/README.md>): components, cycle
   detection, bipartite graphs, grids, multi-source BFS
4. [03 Trees](<03 Trees/README.md>): rooted trees, diameter, Euler tour, LCA
5. [04 Shortest Paths](<04 Shortest Paths/README.md>): Dijkstra, `0-1 BFS`,
   Bellman-Ford, Floyd-Warshall
6. [05 DSU and MST](<05 DSU and MST/README.md>): DSU, Kruskal, Prim
7. [06 Directed Graphs](<06 Directed Graphs/README.md>): topological sort, DAG
   DP, SCC, functional graphs
8. [07 Advanced Connectivity](<07 Advanced Connectivity/README.md>): bridges,
   articulation points, Euler path/circuit

## What this covers

- Graph traversal and basic modeling
- Tree techniques that appear constantly in contests
- Shortest path algorithms needed through intermediate level
- Core graph decomposition ideas such as SCC and bridge finding
- Standard constructive algorithms like MST and Euler traversal

## Not included
- Proofs of Correctness
