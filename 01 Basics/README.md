# 01 Basics

**Target range:** roughly `800-1100`

This section is about learning how graphs are stored and how to traverse them
without getting lost in implementation details.

## Topics

1. [Graph Representation](01-graph-representation.md)
2. [Breadth First Search](02-bfs.md)
3. [Depth First Search](03-dfs.md)

## Goal before moving on

You should be comfortable with:

- building adjacency lists
- running BFS/DFS from one source
- visiting all nodes in a component
- storing parent, depth, and distance arrays
